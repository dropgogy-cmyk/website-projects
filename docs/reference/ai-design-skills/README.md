# AI Design Skills — оригинальные источники и адаптация

В проект добавлены адаптированные рабочие версии двух навыков:
- `skills/adapted/landing-page-design/SKILL.md`
- `skills/adapted/design-to-motion/SKILL.md`

Адаптации не являются дословными копиями. Они сохраняют основные рабочие идеи исходников и согласуют их с требованиями MATVEY PRIME: не выдумывать факты, не имитировать доказательства, учитывать доступность, не навязывать эффекты и проверять только то, что действительно проверено.

## Лицензия и авторство

В предоставленном архиве указана лицензия MIT. Оригинальный README также указывает на заимствования из других MIT-лицензированных проектов. Перед отдельным распространением исходных файлов сохраняй лицензионные уведомления и credits из оригинального архива. Адаптированные файлы в этом репозитории следует отличать от дословных исходников.

## Что изменено намеренно

1. Правдивость важнее конверсии: запрещено выдавать вымышленные отзывы, логотипы, метрики, клиентов, цены и гарантии за реальные.
2. Конкретные шрифты, палитры, отступы и эффекты стали рекомендациями, а не универсальными запретами.
3. Обязательная анимация слогана не используется автоматически.
4. Навык движения необязателен для стандартного лендинга и подключается только при обоснованной задаче.
5. Добавлены требования проекта к доступности, честным формам, приватности, проверкам и отчёту о статусе.

## Как применять в новом проекте

Скопируй `AGENTS.md` и `docs/AI-SITE-DESIGN-GUIDE.md`, затем адаптируй правила под стек, требования клиента и имеющийся протокол качества. Для нового лендинга используй landing-page-design; для showcase-анимации — design-to-motion. Не добавляй оба навыка в обязательный контекст, если задача не требует этого.
