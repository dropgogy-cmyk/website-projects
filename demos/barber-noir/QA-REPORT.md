# BARBER / NOIR — отчёт проверок

Дата фиксации: 2026-10-26

## Реализовано
- [x] Один HTML-документ с семантическими секциями и русским языком страницы.
- [x] Адаптивные CSS-правила для узких и широких экранов.
- [x] Главное действие ведёт к секции формы.
- [x] Мобильное меню имеет кнопку с `aria-expanded`, закрывается по Escape и после выбора ссылки.
- [x] Форма использует подписи, обязательные поля, ограничения длины и встроенную браузерную валидацию.
- [x] Форма не имитирует отправку на сервер: показывает явное сообщение, что данные не отправлены.
- [x] Для анимации появления учтён `prefers-reduced-motion`; контент остаётся доступным без IntersectionObserver.
- [x] Добавлены title, description, Open Graph-метаданные, alt-тексты, skip link и видимые focus-состояния.
- [x] Вымышленный бренд и демонстрационные услуги явно помечены как концепция; реальные цены, отзывы, контакты и достижения не заявляются.
- [x] Удалён ошибочный URL-заполнитель из галереи.
- [x] Убрано повторение одного и того же фото в галерее: для карточки подобран отдельный URL.
- [x] Добавлен обработчик ошибки загрузки: браузер не показывает сломанную иконку изображения; контейнер сохраняет фоновую подложку.
- [ ] Изображения пока остаются внешними ссылками Unsplash; локальные файлы в репозиторий не перенесены.

## Проверено статически в исходном коде
- [x] Основные элементы HTML, CSS и JS находятся в одном файле.
- [x] В исходнике есть обработчики мобильного меню и отправки формы.
- [x] Якорные ссылки ведут на секции страницы.
- [x] В коде не обнаружен прежний URL-заполнитель изображения.
- [x] Состояние формы прямо объясняет, что отправка на сервер не происходит.

## Не проверено в браузере
- [ ] Фактическая загрузка и кадрирование каждого внешнего изображения — ссылки обновлены, но загрузка с устройства пользователя не подтверждена.
- [ ] Визуальное отображение на реальных ширинах мобильного, планшета и desktop.
- [ ] Реальное поведение всех переходов в браузере и отсутствие ошибок консоли.
- [ ] Валидность HTML по внешнему валидатору.
- [ ] Автоматические тесты, Lighthouse/Core Web Vitals, полная проверка WCAG и совместимость с браузерами.
- [ ] Работа сайта без интернета: шрифты и фотографии всё ещё требуют внешних ресурсов; локальных файлов изображений пока нет.
- [ ] Реальная запись: backend и интеграция намеренно не подключены.

## Перед коммерческим использованием
1. Заменить название, тексты, услуги и изображения на утверждённые заказчиком материалы; для стабильной работы добавить оптимизированные локальные файлы фото.
2. Уточнить цены, адрес, часы работы, контакты и реальные условия.
3. Подключить согласованный канал записи; только после этого менять сообщение формы на реальное подтверждение отправки.
4. Проверить разрешения и условия использования фото.
5. Провести браузерный тест на мобильном и desktop, затем повторить проверки после исправлений.

**Статус:** прототип реализован; статическая проверка исходника выполнена; браузерная и интеграционная проверка не выполнены. Не считать готовым к коммерческому запуску.
