# BARBER / NOIR — demo landing page

Демонстрационный одностраничный сайт-концепция для барбершопа. Не представляет реальную компанию.

## Файлы
- `index.html` — страница, стили и интерактивность в одном файле.
- `BRIEF.md` — цель, аудитория, подтверждённые факты, допущения и критерии приёмки.
- `QA-REPORT.md` — фактически выполненные проверки и ограничения.

## Как посмотреть
Откройте `index.html` в современном браузере. Для внешних изображений и шрифтов требуется подключение к интернету.

## Важно
Форма сейчас работает только как демонстрация проверки полей в браузере. Данные никуда не отправляются, настоящая запись не создаётся. Перед коммерческим запуском нужно заменить демонстрационные материалы на согласованные данные реального бизнеса, подключить реальный канал записи и протестировать страницу в браузерах.
