## Концепция

Не очередной тёмный сайт с пламенем, а современная гастрономическая редакция: тёплая бумажная база, чернильная типографика, томатно-красный акцент, крупная фотография и меню как главный рабочий раздел. Путь пользователя: увидеть концепцию → отфильтровать категории меню → связаться с заведением.
