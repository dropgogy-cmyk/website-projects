# GrillBar163 — отчёт проверок

Дата: 2026-10-26

## Реализовано в исходнике
- [x] Один HTML-файл с CSS и JS без сторонних JS-библиотек.
- [x] ru, viewport, title, description, Open Graph.
- [x] Hero, концепция, меню с фильтрами, CTA заказа, галерея, шаги и контакты.
- [x] Мобильное меню с aria-expanded, Escape и закрытием после перехода.
- [x] Фильтры меняют видимость карточек.
- [x] Телефон tel:, Telegram открывается отдельно.
- [x] Заметная маркировка концепта, без цен и отзывов.
- [x] Alt-тексты, lazy loading для контентных фото, reduced-motion.
- [x] Обработчик ошибки скрывает сломанное изображение; это не гарантирует доступность внешних ссылок.
- [x] Нет формы, имитирующей отправку заказа.

## Статическая проверка исходника
- [x] Один основной h1.
- [x] ID в документе уникальны; внутренние якоря ведут к существующим ID.
- [x] Фильтры и карточки имеют соответствующие data-атрибуты.
- [x] Навигационная кнопка связана с nav через aria-controls.
- [x] Текст поясняет, что заказ через сайт не оформляется.

## Не проверено
- [ ] Просмотр в браузере на мобильном и desktop.
- [ ] Доступность Unsplash-изображений из сети пользователя.
- [ ] Работа внешнего Telegram, актуальность телефона, адреса и часов.
- [ ] HTML validator, Lighthouse, Core Web Vitals, полная проверка WCAG.
- [ ] Кроссбраузерность, консоль и полная клавиатурная проверка.
- [ ] Право использования будущих фото/логотипа и согласование публикации.

## Блокеры коммерческого запуска
1. Подтвердить с владельцем адрес, контакты, график и канал заказа.
2. Получить актуальное меню, цены, состав/аллергены и условия доставки.
3. Заменить стоковые фото на согласованные материалы.
4. Согласовать использование бренда и публикацию концепта.
5. Если нужны онлайн-заказы, спроектировать реальную интеграцию отдельно.

**Итог:** концепт реализован в исходнике; браузерная проверка и подтверждение данных владельцем не выполнены. Не готов к коммерческому запуску.
