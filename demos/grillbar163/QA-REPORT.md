# GrillBar163 — отчёт проверок

Дата: 2026-10-26  
Версия: редакционная концепция «Редакция у огня».

## Реализовано в HTML

- [x] Один самостоятельный HTML-файл с CSS и JavaScript, без сторонних JS-библиотек.
- [x] Русский язык документа, viewport, title, description и Open Graph метаданные.
- [x] Собственная арт-дирекция: тёплая бумажная палитра, чернильный текст, красный акцент, редакционная типографика и асимметричный hero.
- [x] Один основной H1, меню с фильтрами, контактная секция и понятный путь от просмотра меню к связи.
- [x] Мобильная навигация с aria-expanded и закрытием после выбора ссылки.
- [x] Фильтры меню переключают категории без перезагрузки.
- [x] Телефон оформлен как tel:-ссылка; Telegram открывается в отдельной вкладке с rel=noopener noreferrer.
- [x] Кнопки и ссылки имеют назначение; пустых href="#" нет.
- [x] Alt-тексты у фотографий, lazy loading для контентных изображений; у hero задан fetchpriority=high.
- [x] Уважение prefers-reduced-motion. Анимация появления не скрывает контент, если IntersectionObserver недоступен.
- [x] Концепт явно помечен как неофициальный. Нет неподтверждённых цен, отзывов, рейтингов или формы, имитирующей заказ.

## Выполненная статическая проверка

- [x] Файл записан в ветку redesign/grillbar163-editorial.
- [x] Повторно проверена логика graceful fallback для анимации появления.
- [ ] Полный автоматический HTML-валидатор не запускался.
- [ ] Браузерный тест не запускался; не заявляем, что визуально проверены все размеры экрана.

## Не проверено

- [ ] Визуальный просмотр на реальном мобильном устройстве и desktop.
- [ ] Доступность внешних Unsplash-изображений в разных сетях и их точное визуальное соответствие alt-текстам.
- [ ] Актуальность телефона, адреса, Telegram и меню; эти сведения пока основаны на сторонних каталогах.
- [ ] Полный keyboard-only тест, скринридер, контраст по WCAG, Lighthouse/Core Web Vitals и кроссбраузерность.
- [ ] Право на использование будущих фото, логотипа и фирменных материалов; согласование публикации концепта.
- [ ] Проверка сайта официального домена: он не открылся в исследовательской среде, что не подтверждает отсутствие сайта.

## Блокеры коммерческого запуска

1. Связаться с владельцем и подтвердить цель сайта, адрес, телефон, часы и официальный канал заказа.
2. Получить актуальное меню с ценами, составом/аллергенами, весом порций и условиями доставки.
3. Заменить фотобанк на одобренные фото блюд и получить разрешение на использование бренда.
4. Проверить адреса ссылок и реальное поведение на мобильных устройствах.
5. Если владелец хочет оформление заказа на сайте, отдельно спроектировать и проверить реальную интеграцию.

**Итог:** новая визуальная концепция реализована в коде. Статус — прототип для обсуждения, не официальный сайт и не коммерческий релиз. Браузерная проверка и подтверждение фактов владельцем ещё не выполнены.
